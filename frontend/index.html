Como usar o sistema

Comece pelo cadastro de pessoas. Usuários e pacientes são criados a partir delas, e cada agendamento liga um paciente a um médico.

  1. 1 Pessoas Nome e data de nascimento. Todo cadastro começa aqui.
  2. 2 Usuários Acesso ao sistema para administradores e médicos.
  3. 3 Pacientes CPF, telefone e convênio de quem é atendido.
  4. 4 Agendamentos Consultas entre paciente e médico, com o status de cada uma.
